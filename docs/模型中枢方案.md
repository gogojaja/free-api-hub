# 模型管理中枢方案（DeepSeek + Qwen 双主模型）

**版本**：v1.2（定稿）　**日期**：2026-08-29　**状态**：SIGNED_OFF（两轮评审通过）

## 1. 目标与总体原则

- 本项目即「模型管理中枢」：统一管理 DeepSeek + Qwen 双主模型的 API 路由与成本。
- **总体原则**：削减不必要支出；必要时使用最合适的模型 API。
- 演进路线：**手动选择（一期）→ 智能路由（二期）**。

## 3. 路由仲裁链（manual_override 契约, ADR-010）

仲裁优先级：**manual_override > 显式命中 alias > priority/capability 排序 > 兜底全池 failover**。
- 未命中 / 未知模型 / 裸下游模型名（opencode `free-api-hub`）→ 保持全池 failover。
- 一期只实现 manual_override 手动指定；schedule 时段调度归二期（叠加式非破坏）。

## 4. 每周监测机制（ADR-011）

`scripts/model_monitor.py` 每周一巡，产出周报 CSV（diff 上期→本期）：
1. 基准价 → `台账/24_模型价格.csv`
2. 优惠（夜间/短时/免费额度）→ `台账/26_优惠日历.csv`
3. 免费额度（额度量/刷新周期/刷新时间/剩余）→ `台账/27_免费额度.csv`
- 周报含「免费额度将重置/已耗尽 → ACTION=切换建议」预警列。
- 监测结果留痕入 `台账/13_安全审计台账.csv`（AUD 每周）。

## 5. 台账契约

- `24_模型价格.csv`：平台/模型/输入$/输出$/缓存命中$/context/output/来源T1/核验日期
- `26_优惠日历.csv`：平台/模型/优惠类型[夜间|短时|免费额度]/优惠力度/开始时间/**结束时间**/来源/核验日期
- `27_免费额度.csv`：平台/模型/额度类型/额度量/刷新周期/刷新时间/当前状态/来源/核验日期

## 6. 成本预算

- 每周监测成本 ≤ 1K token/巡（远低于节省，不触发铁律 #9 预警）。
- 铁律 #9 闸门：大批量任务先报价三选一 + 登记 `台账/40_大模型成本台账.csv`。
