# environment — 3 套环境（dev / test / prod）

> 配套 MCP：`freeApiHub` 仅本地子进程（stdio，无端口）。
> 单一真实源：`台账/20_环境配置.csv`（环境组/隔离方式/端口区间/共用边界/权限角色）。

## 拓扑（双环境组）
- **nonprod（非生产组）**：dev + test 共用一套平台实例，逻辑细分。
  - dev：开发联调，脱敏数据，禁生产数据。
  - test：测试验证（兼 staging，发布前按生产同形状验证），禁生产写权限。
- **prod（生产组）**：独立部署，真实数据，变更须 CAB/回滚预案。

## 端口隔离（进程级第一道约束）
| 服务 | nonprod-dev | nonprod-test | prod |
|------|-------------|--------------|------|
| 网关 Web API | 30000 | 30100 | 8080(网关映射) |
| 管理 Admin API | 30001 | 30101 | 8081 |
| 状态存储 | 30002(sqlite) | 30102(sqlite) | 5432(集群) |

## 密钥与 RBAC
- key 仅存别名（`{file:~/.config/opencode/<provider>-api-key}`），真实值经 `.secrets/` 注入，禁入库。
- 开发者：nonprod 读写、prod 只读；运维：prod 唯一写权限（管线化 + break-glass 留痕）。
- 所有端口/资源注册 CMDB（`25_环境资源清单.csv`，先注册先得；多项目冲突升阶仲裁）。

## 检查（门禁）
- `check_gate` 比对 `20_环境配置.csv` ↔ 实际运行（端口监听/数据目录/卷名），不一致即阻断。
- 冒烟在对应环境通过后，才允许推进/发布。
